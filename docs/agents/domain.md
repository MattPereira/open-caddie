# Domain Docs

## Layout

Single-context repository:

- `GLOSSARY.md` at repository root
- `docs/adr/` for architectural decisions

## Consumer rules

Before exploring, read `GLOSSARY.md` and relevant ADRs when present. If absent, proceed silently.

Use terminology defined in `GLOSSARY.md`. Avoid synonyms it rejects. Note genuine terminology gaps for `/domain-modeling`.

Explicitly surface work conflicting with an existing ADR rather than silently overriding it.
